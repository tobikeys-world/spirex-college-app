📌 About the Project

EduSphere College is a responsive college website interface designed to present important academic and campus information in a clean and user-friendly way.

The website provides sections for:

- Departments
- Courses
- Faculty
- Students
- Events
- College information
- Contact details

The project also includes interactive JavaScript features such as mobile navigation, dark/light mode, local theme storage, and scroll animations.

✨ Features

- 📱 Fully responsive design
- 🏫 College information section
- 📚 Departments section
- 🎓 Courses and programmes
- 👨‍🏫 Faculty section
- 📅 Upcoming events
- 📞 Contact information
- 🌙 Dark/light mode
- 💾 Theme preference saved with "localStorage"
- 📱 Responsive mobile navigation
- ✨ Scroll-reveal animations
- 🔗 Smooth navigation between sections

🛠️ Technologies Used

- HTML5 — Website structure and semantic content
- CSS3 — Styling, layouts, animations and responsive design
- JavaScript — Interactivity and dynamic functionality
- Font Awesome — Icons
- LocalStorage API — Saving theme preference
- Intersection Observer API — Scroll-reveal animations

⚙️ JavaScript Functionality

Mobile Navigation

The hamburger menu allows users to open and close the navigation menu on smaller screens.

Dark/Light Mode

Users can switch between light and dark themes using the theme button.

Local Storage

The selected theme is saved using the browser's "localStorage", allowing the preference to remain after refreshing the page.

Scroll Reveal

The "IntersectionObserver" API is used to reveal cards as they enter the user's viewport.

📱 Responsive Design

The interface has been designed to work across:

- Desktop computers
- Laptops
- Tablets
- Mobile phones

CSS media queries automatically adjust the layout according to screen size.
